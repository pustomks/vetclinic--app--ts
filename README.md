# VetClinic App 🐾

Современное Single Page Application (SPA) для автоматизации рабочих процессов ветеринарной клиники: ведение базы питомцев, управление карточками пациентов, логика фильтрации и персональные списки избранного.

## 🚀 Технологический стек

- **Core:** React 19, TypeScript
- **State Management:** Redux Toolkit (Async Thunks)
- **Data Fetching:** Axios (с кастомными Interceptors)
- **Forms & Validation:** React Hook Form
- **UI Components:** Ant Design (antd)
- **Build Tool:** Vite 8
- **Code Quality:** ESLint, Oxlint (ультрабыстрый статический анализ)

## 🛠 Архитектура проекта и инженерные решения

В проекте реализована модульная структура со строгим разделением слоев логики (`api`, `store`, `hooks`, `components`, `types`):
- **Сетевые перехватчики (Axios Interceptors):** Настроен Request Interceptor для динамического прикрепления JWT-токена (`Bearer`) из Redux-стора ко всем защищенным запросам. Реализован Response Interceptor для глобального отслеживания серверных ошибок (автоматический Logout и сброс ролей при коде `401 Unauthorized`).
- **Оптимизация рендеринга форм:** Интегрировал UI-компоненты Ant Design с библиотекой `react-hook-form` через паттерн с обёрткой `Controller`. Это позволило изолировать ввод данных и избежать избыточных ререндеров формы при заполнении.
- **Управление асинхронным стейтом:** Бизнес-логика (Fetch, Add, Update, Delete) вынесена в асинхронные thunk-экшены Redux Toolkit. Для обработки результатов и вывода алертов на клиенте используется механизм `.unwrap()` над промисами.
- **Безопасность типов (Advanced TS):** Спроектирована сквозная типизация интерфейсов. Активно используются встроенные утилиты TypeScript (`Omit`, `Pick`, `Partial`, `Readonly`) для деривации типов форм и DTO без дублирования кодовой базы (например, `CreatePet = Omit<Pet, "id">`).

## 📦 Локальный запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Установить зависимости:
   ```bash
   npm install
   ```
3. Запустить сервер для разработки:
   ```bash
   npm run dev
   ```
